
# Темы оформления интерфейса

Программа GEDKeeper имеет функцию переключения между темами оформления интерфейса.
Это делается в меню "Сервис\Темы", при этом переключение происходит сразу, без перезагрузки программы.

На данный момент в программе реализованы следующие темы:
- Стандартная (зашита в программу и не может быть изменена);
- Светлая;
- Темная;
- "Лесная" (смягченные зеленые тона; наименее проработанная из всех, экспериментальная).

Темы поддерживают изменения цвета основных элементов оформления программы,
типа и размера шрифта, а также глифов/иконок меню.

Любой пользователь программы может скопировать файл произвольной темы в папке themes в месте установки программы,
дать своё имя файлу, изменить имя темы в самом файле (обязательно для корректной работы программы) и настроить цвета так, как ему нравится.
Визуального редактора в самой программе для этого нет.

Пользователи могут присылать свои файлы тем. Гармоничные и интересные могут быть включены 
в комплект программы с фиксацией автора в истории разработки программы.

Внимание: линейка версий GK v3.xx основана на подходах, которые ограничивают возможности 
изменения цветов меню, компонентов с закладками и некоторых других.

----

Для разработки своих тем важно знать следующее:
0. Темы расположены в папке `themes` в корневой папке куда установлена программа (напр. `C:\Program Files\GEDKeeper3\themes`).
1. Файлы тем используют формат данных YAML (https://ru.wikipedia.org/wiki/YAML).
2. Важно знать: Темы загружаются из файлов на диске в момент запуска программы. Это архитектурное ограничение, не изменяемое.
  - при разработке темы, копируете файл с новым вариантом своей темы в папку, перезапускаете программу;
3. Разработку своих тем лучше начинать с создания копии и модификации темы "Светлая" (файл `gk_light.yaml`) - она базовая, простая и маленькая.
4. Типы настраиваемых компонентов пользовательского интерфейса:
  - Font                        - имя шрифта, строка, например "Verdana"
  - FontSize                    - размер шрифта в em, дробное число в строке, например "8.5"
  
  *цвета* - все в формате "#FFFFFF", стандартный веб-RGB
  
  - Editor                      - фон любого редактирующего текст компонента (поля ввода строки или текста, выпадающие списки)
  - EditorText                  - цвет текста в редактирующих компонентах
  - Control                     - фон компонентов общего назначения (панели, групповые рамки и т.п., дефолтный цвет графиков (там есть еще свой))
  - ControlText                 - цвет текста
  - Window                      - фон окон общего назначения (не диалоги!), окна - это, например, основное, или графиков, или статистики (чаще всего в них цвет фона закрыт множеством других компонентов);
  - WindowText                  - цвет текста в окнах;
  - Dialog                      - фон в диалогах; как правило виден; диалоги - это все формы для редактирования чего-либо, например, диалог редактирования персон
  - DialogText                  - цвет текста в диалогах (редко встречается);
  - ButtonFace                  - цвет лицевой стороны кнопок (Отменить, Закрыть и разные другие);
  - AccentButtonFace            - цвет лицевой стороны акцентированных кнопок (например, кнопки Ок или Принять);
  - ButtonBorder                - цвет границы кнопок (может быть одинаковым с цветом лицевой стороны для создания эффекта плоских);
  - ButtonText                  - цвет надписей кнопок;
  - Strip                       - фоновый цвет всех панелей инструментов и меню;
  - Dropdown                    - фоновый цвет выпадающих панелей (выпадающие меню и выпадающие списки у панелей с кнопками);
  - MenuBorder                  - граница меню (у выпадающих меню);
  - MenuItemSelected            - цвет выбранного (под мышкой) пункта меню;
  - Link                        - цвет текста гипер-ссылок (правая панель информации главного окна);
  - Grid                        - цвет фона и ячеек всех табличных компонентов;
  - GridHeader                  - цвет заголовка таблиц;
  - GridHeaderText              - цвет текста заголовка таблиц;
  - GridText                    - цвет текста в ячейках таблиц;
  - Tab                         - фоновый цвет закладок у компонентов с закладками (табами), например закладки типов записей в главном окне;
  - TabHighlight                - цвет закладки под мышкой;
  - TabSelected                 - цвет текущей активной закладки;
  - HighlightReadabilityRows    - цвет строк всех таблиц, для повышения удобства чтения (Readability) - должен *не контрастно* отличаться от Grid-цвета;
  - HighlightUnparentedIndi     - цвет строк основного списка персон для выделения персон без родителей, если включена эта опция;
  - HighlightUnmarriedIndi      - цвет строк основного списка персон для выделения персон без семьи, если включена эта опция;
  - HighlightInaccessibleFiles  - цвет строк основного списка медиа-записей для выделения медиа без доступного файла, если включена эта опция;

  *размеры*

  - ToolItemsImageSize          - размер иконок панелей инструментов, целое число в кавычках, например "20"
